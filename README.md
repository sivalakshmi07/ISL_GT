# ISL Vision

An Indian Sign Language (ISL) recognition system developed using **Computer Vision and Deep Learning**.

## 📌 Project

The project has two main components:

- **Static Alphabet Recognition** – CNN-based recognition of ISL alphabets A–Z from images.
- **Dynamic Gesture Recognition** – CNN-LSTM based recognition of selected ISL gestures from videos.

## 🛠️ Technologies Used

- Python
- TensorFlow & Keras
- OpenCV
- NumPy
- Pandas
- Google Colab / Jupyter Notebook

## 📊 Dataset

### Static Alphabet
- 23,354 images
- 26 classes (A–Z)
- 18,154 training images
- 5,200 testing images

### Dynamic Gestures
- 145 videos
- 7 gesture classes
- 20 frames extracted from each video

## 📁 Files

- `GroupProjectImagePart.ipynb` – Static alphabet CNN
- `GroupProjectVideoPart.ipynb` – Dynamic gesture CNN-LSTM
